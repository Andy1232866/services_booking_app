# Aplicación de Reserva de Servicios

Proyecto para la materia "programación de aplicaciones móviles"

## Sobre el Proyecto

Este proyecto fue desarrollado con la finalidad de poner en práctica todo lo aprendido durante ésta materia a un nivel más avanzado, aplicando temas, como por ejemplo:

- Bases de Datos (Supabase - Base de Datos SQL)
- Gestión de Usuarios/Login/Register/User Authentication (Firebase / Base de Datos no SQL)
- Animaciones
- Multi-navegación, etc.

En el siguiente link se da una demostración de la aplicación, funcionamiento, diseño, etc:

https://youtube.com/shorts/xCpa772WCxg?feature=share

Características no mencionadas, pero desarrolladas:

1. Dependiendo de la hora, la aplicación dará la bienvenida según esta ("Buenos días", "Buenas tardes", "Buenas noches") seguido del nombre de usuario.
2. Cuando un servicio cambia de estado (3 posibles: Cancelado, Completado, En Reserva) también cambia al apartado en el cuál pertenece (también cambia en el calendario).
3. La base de datos de supabase del proyecto se encuentra alojada de manera local, no se encuentra en la nube.

Características a desarrollar:

1. Concluir el apartado de chat, para que el usuario que reserva pueda interactuar con la persona que ofrece el servicio.
2. Agregar una vista especial para el usuario que ofrece el servicio, esto para que exista un sistema de ambas partes.
3. Añadir un sistema de notificaciones, para que la aplicación pueda notificar cuando la fecha del servicio se acerque (recordatorio)
